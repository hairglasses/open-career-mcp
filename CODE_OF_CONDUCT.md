# Code of Conduct

This project is a public, professional engineering space.

## Expected Behavior

- Be respectful and direct.
- Keep criticism focused on code, docs, behavior, and project fit.
- Help maintain the public boundary: do not request or share credentials,
  account data, personal career data, host details, or non-public operational
  details.

## Unacceptable Behavior

- Harassment, threats, or attacks on contributors.
- Publishing non-public information without explicit permission.
- Attempts to introduce credentials, tracking, hidden network behavior, live
  account connectors, or real career/application data.

## Reporting

Report conduct concerns to the maintainer through GitHub or the contact path in
the maintainer profile. Security issues should use `SECURITY.md`, not public
issues.
